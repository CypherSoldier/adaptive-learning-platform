# Adaptive Learning Platform

A modern, intelligent adaptive learning platform for mastering programming languages (Python, C++, JavaScript, etc.). The system personalizes the learning experience using an adaptive engine that adjusts question difficulty based on the user's real-time skill and confidence scores.

Built with a clean separation of concerns, modern tech stack, and a focus on performance and scalability.

## 🚀 Features

- **Adaptive Question Engine**: Automatically selects the next question based on user skill level, confidence, and learning track using Gemini AI API
- **User Skill Profiling**: Tracks skill_score, confidence_score, and attempt history per learning track
- **Submission & Evaluation System**: Records user answers with time tracking and correctness
- **Authentication & User Management**: Secure password handling with change password functionality
- **Multi-Track Support**: Python, C++, JavaScript (easily extensible)
- **RESTful API**: Built with FastAPI for high performance
- **Modern Frontend**: Next.js with Bootstrap for a responsive UI
